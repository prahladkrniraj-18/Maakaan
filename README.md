# 🏠 MAAKAAN – Full-Stack Property Rental Platform

MAAKAAN is a full-stack property rental web application (Airbnb-style) that allows users to list, search, and book rental properties seamlessly.

---

## 🚀 Features

- 🔐 User Authentication (Signup/Login/Logout)
- 🏘️ Property Listing (Add, Edit, Delete Listings)
- 🔍 Dynamic Property Search & Filtering
- 📅 Booking System
- 📱 Responsive UI for better user experience
- 🗄️ Efficient database management using MongoDB

---

## 🛠️ Tech Stack

**Frontend:**

- React.js
- HTML, CSS

**Backend:**

- Node.js
- Express.js

**Database:**

- MongoDB

**Other Tools:**

- REST APIs
- Git & GitHub
